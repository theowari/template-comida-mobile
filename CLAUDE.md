# CLAUDE.md

## Preferences

- Never use emojis anywhere (UI, copy, code, comments, commit messages). Use an icon library instead (e.g. lucide, react-icons, Phosphor).
- Always use Unsplash stock images for photography and placeholder imagery.
- Always build websites mobile first: design for small screens by default, then scale up with larger breakpoints.
- Use the available skills as much as possible whenever it makes sense for the task at hand.
